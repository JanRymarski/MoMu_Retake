MoMu — Fashion Museum Antwerp

An interactive editorial website inspired by MoMu — Fashion Museum Antwerp, exploring Belgian fashion, designers, and the stories behind garments.

Concept

The project reimagines a museum fashion story as a digital editorial experience. Instead of simply displaying garments, the website uses storytelling, visual design and interaction to explore the ideas, history and creative processes behind fashion.

The design is inspired by MoMu's editorial identity, combining large-scale imagery, typography, animation and interactive elements to create an immersive scrolling experience.

Technologies
HTML5 — Semantic page structure
SCSS — Styling and responsive layouts
JavaScript — Interactions and functionality
GSAP — Scroll-based animations and transitions
Figma — Wireframes, UI design and prototyping
Figma AI — Generated visual assets

Features
Editorial-style long-scrolling layout
Responsive design
Scroll-triggered animations using GSAP
Interactive garment exploration
Hover and click-based interactions
Animated transitions between sections
Museum and designer storytelling
Calls-to-action for exploring other designer stories
